# eugene-kontra-downloads
Official free downloads for Eugen Kontra plugins, overlays and tools.

## OBS plugins

### TuneWink 2.0
A free music overlay for OBS Studio with an English-first interface, Russian language buttons, ten skins, glass-inspired controls and a local Windows media bridge. Includes live preview with demo tracks, connection diagnostics, safe OBS source creation, settings import/export, and an optional Streamer.bot `!song` import.

- [Download the complete Windows source and build package](https://github.com/EugenKontra/eugene-kontra-downloads/blob/main/downloads/TuneWink-v2.0.0-source.zip)
- [Browse GitHub Releases](https://github.com/EugenKontra/eugene-kontra-downloads/releases) for a compiled installer after the Windows build and installation checks have passed.
- [Read the Streamer.bot setup guide in the package](https://github.com/EugenKontra/eugene-kontra-downloads/blob/main/downloads)

TuneWink reads Windows media-session details locally. It does not need a Spotify sign-in, TuneWink account, or cloud service.

The repository's Windows workflow compiles the plugin/helper and builds the installer and retail ZIP. It stores CI artifacts for review; it does not publish a release automatically.
